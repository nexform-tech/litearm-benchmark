# Documentation

Documentation for `litearm-benchmark`, the current-loop torque estimation
accuracy evaluation tool for the LiteArm robotic manipulator series.

## Start here

- [Setup](setup.md): install, run, and verify the project.
- [Architecture](architecture.md): modules, data flow, and boundaries.

## Tasks

- Evaluate current-loop torque estimation accuracy against the firmware's
  rigid-body inverse-dynamics model.
- Identify dominant error sources (gravity, inertia, friction, current-loop
  calibration, filter delay) with evidence and suggestions.
